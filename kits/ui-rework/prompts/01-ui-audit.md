# 01 — UI audit

- Ghi F-UI: màn hình/luồng, điều cụ thể (CTA chìm, chữ mờ, spacing lệch).
- Chụp before; đọc tokens/components; a11y/keyboard/responsive.
- Danh sách “giữ lại” và “đổi”.
- Optional Impeccable `critique`: `docs/source`/`proposed`; không thay before/after.
- Pattern/a11y reference: GitHub/W3C; ghi nguồn; không copy mù.
- Output: before + findings + phạm vi.
