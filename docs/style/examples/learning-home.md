# PAGE SPEC — Learning home (ví dụ)

- Loại web/trang: Learning platform / home dashboard.
- Mục tiêu người dùng: biết học gì tiếp, ôn gì, giữ tiến độ.
- Audience/entry: người học quay lại, có thể mới hoặc đang học dở.
- 5 giây hiểu gì: “Hôm nay học gì?” + tiến độ + một CTA.
- Hành động chính: Tiếp tục bài đang học; phụ: Ôn 5 phút.
- Nội dung/section order: lời chào → continue card → daily goal → review due → gợi ý → tiến độ.
- Menu/vị trí IA: Home / Courses / Practice / Progress / Profile (5 mục); CTA tách riêng.
- Hierarchy (H1/CTA/3 mức): 1 H1; 1 CTA chính; 3 mức nhấn (continue, goal, progress).
- States: người mới (empty), có bài dở, không có review due, loading, lỗi.
- Responsive: mobile continue card đầu; nav dưới 5 mục; 320 reflow.
- A11y/motion: focus-visible, target ≥44px, transcript, reduced-motion; không autoplay.
- Metrics: resume rate, lesson start, review completion, D1/D7 return.
- Non-goals: XP spam, badge shop, notification dày, hiệu ứng nền.
- Learning: bài đang học / continue / review due / level-XP / quiz.
- Evidence/owner: ví dụ pattern, không phải project_verified; owner F-UI pending.
