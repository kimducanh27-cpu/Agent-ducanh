# Superpowers routing

- Đọc `core/toolbox/superpowers-routing.md`.
- `using-superpowers` đầu phiên.
- Tối đa 1 skill chính + 1 skill kiểm chứng mỗi bước.
- Bug rõ → `systematic-debugging`; không `brainstorming`.
- Text/style → không ép `test-driven-development`.
- Browser dùng chung → không `dispatching-parallel-agents`.
- Cùng file → không `subagent-driven-development`.
- Trước “xong” → `verification-before-completion`.
- Thiếu skill → toolbox/fallback; không bịa.
